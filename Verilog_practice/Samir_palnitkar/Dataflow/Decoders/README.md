# DECODERS: 

A decoder is a digital logic circuit that converts n input lines into up to 2^{n} unique output lines. For every input combination, only one output channel becomes active while all other outputs remain inactive.
Common Types:
2-to-4 Line Decoder: Uses 2 inputs to drive 4 outputs (2²).
3-to-8 Line Decoder: Uses 3 inputs to drive 8 outputs (2³), often used for binary-to-octal conversion.
4-to-16 Line Decoder: Uses 4 inputs to drive 16 outputs (2⁴).
BCD-to-Decimal Decoder: Converts 4-bit binary-coded decimal inputs into 10 distinct decimal outputs.

Main Uses
Memory Addressing: Selecting specific memory chips or registers in a computer.
Data Demultiplexing: Routing a single data signal to one of many destinations.
Display Drivers: Driving multi-segment displays or seven-segment indicators.
Instruction Decoding: Translating operation codes inside a CPU
